# Promotion Site

Static landing page for the Promotion Site launch.

## Stack
- Plain HTML / CSS (no build step)
- Google Fonts: Cormorant Garamond + Inter
- Quiet-luxury 3-tone palette: near-black `#0B0B0F` + gold `#B8963E` + cream `#FAF6EE`

## Local preview
```bash
cd public
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy
Deployed to DigitalOcean App Platform as a static site.
